# Knowledge Register

Track **core knowledge** required to own and debug the project. Add specific topics as features are designed.

| Topic | Related feature | Level | Status | Evidence / Notes |
| --- | --- | --- | --- | --- |
| — | — | — | — | — |

**Level:** `Core`, `Supporting`, `Internal / Optional`.

**Status:** `To learn`, `Learning`, `Need practice`, `Verified`, `Review needed`, `Deferred`.

- Core concepts must be verified before closing the corresponding feature.
- Review selected previously verified concepts during the weekly review to reduce forgetting.
- `Deferred` is acceptable only when the topic is not essential to correctness or safety; record the reason.
